## Introdução

####  Esses códigos foram realizados em forma de lista de exercícios recomendados pelo Grupo de Estudos para Maratona de Programação - GEMA, grupo da Universidade de São Paulo, campus de São Carlos.

## Organização

#### Cada pasta corresponde à plataforma que os problemas estão hospedados, para facilitar a procura, em vez de ordenar por assuntos. A grande maioria dos exercícios foram realizados em C++ pois é a recomendada pelo grupo, além de ser vista durante a graduação.

## Assuntos

° Comandos básicos

° While, for, strings

° Vetores, matrizes, operações bitwise

° Funções, complexidade

° STL 1 - vector, set, pair, multiset

° STL 2

° Somas parciais, busca binária

° Two pointers, sliding window
